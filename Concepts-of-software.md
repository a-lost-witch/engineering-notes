# 1. What is software?
Software is a set of instructions, programs, or data that tells a computer what to do.
# 2. What are the types of software?
Software is mainly divided into two major categories:

## a) System Software
System software controls and manages the computer hardware and provides a platform for other software to run.

## Examples:
Operating systems
Device drivers
Utility programs
Common Examples:
Windows 11
macOS
Linux
Functions:
Manages memory
Controls CPU
Handles files
Connects hardware and applications

## Subtypes of System Software:
- ### Operating System (OS):
  Acts as the main controller of the computer.

  ### Examples:
  Windows
  Linux
  Android

- ### Device Drivers:
  Help hardware communicate with the computer.
 
  ### Example:
  Printer driver
  Graphics driver

- ### Utility Software
  Helps maintain and optimize the system.

  ### Examples:
  Antivirus
  Disk cleanup tools
  Backup software
 
 ## b) Application Software
Application software is designed for users to perform specific tasks.

### Examples:
Browsing internet
Editing photos
Playing games
Writing documents
Common Examples:
Microsoft Excel
Adobe Photoshop
Minecraft

### Types of Application Software:
- ### General Purpose Software
  Used for everyday tasks.

  ### Examples:
  Word processors
  Web browsers
  Media players

- ### Specialized Software
  Made for a particular job or industry.
  ### Examples:
  Hospital management software
  CAD software for engineering
  Accounting software
